# Colab Notebooks

A small collection of runnable Google Colab notebooks.

## Notebooks

- **[Weight.ipynb — Predicting Car Weight with Linear Regression](Weight.ipynb)**: a regression exercise using real UCI Auto MPG data, a held-out test set, a mean baseline, evaluation metrics, and an actual-vs-predicted plot. [Open in Colab](https://colab.research.google.com/github/NorkulovAzim/colab-intro-notebook/blob/main/Weight.ipynb).
- **[Welcome to Colaboratory](welcome-to-colaboratory.ipynb)**: Google Colab's introductory notebook. [Open in Colab](https://colab.research.google.com/github/NorkulovAzim/colab-intro-notebook/blob/main/welcome-to-colaboratory.ipynb).

## Data source

The regression notebook uses the UCI Machine Learning Repository's [Auto MPG dataset](https://archive.ics.uci.edu/dataset/9/auto+mpg), licensed under CC BY 4.0. Citation: Quinlan, R. (1993), [https://doi.org/10.24432/C5859H](https://doi.org/10.24432/C5859H). The notebook documents the source and caveats.

The Colab introduction is attributed in its notebook and was retrieved from a publicly shared [GitHub Gist by MansurCompAI](https://gist.github.com/MansurCompAI/4d3eaefcd52b5a489aba217ccd0bb8af), which identifies Google's Colab intro URL as the original source.
